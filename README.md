📌 Project Objective

The objective of this project is to:

Validate the functional correctness of OpenCart

Identify UI, security, and performance issues

Ensure a stable and reliable shopping experience for users

Demonstrate best practices in manual software testing


🧩 Application Under Test (AUT)

OpenCart is an open‑source e‑commerce platform used for online stores. It supports:

User management

Product catalog

Shopping cart

Checkout & payments

Admin management

SEO, reports, and extensions
